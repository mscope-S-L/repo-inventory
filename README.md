# Repo Inventory

Inventario de los repositorios de mscope: cuáles tenemos bajo nuestro ownership, cuáles deberíamos consolidar o llevarnos a un repo propio, y el estado de esa migración.

## Por qué existe

Varios equipos han acabado con repos dispersos (propios, forks, o en cuentas personales) sin un registro central de quién es el owner real. Este repo es el punto de partida para:

- Listar los repos existentes y su ownership actual.
- Decidir cuáles merece la pena centralizar.
- Trackear la migración.
